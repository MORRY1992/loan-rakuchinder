# ローン計算・PC配置改善 Implementation Plan

> 実行：総本部が既存の委任範囲で直接実装し、独立レビュー後に通常公開する。

**Goal:** PCで借入条件と主要結果を同時に見比べられる画面へ修正する。

**Architecture:** 単一HTMLの既存DOMと計算コアを維持。60rem以上では入力・結果を2列、狭幅は従来の1列。Web未配信広告の仮枠を隠し、Androidの別SDK制御を維持。

**Tech Stack:** 既存HTML/CSS/JS、Nodeの既存テスト・ビルド。

**Spec:** 2026-11-08の総本部正式提案、第4条の第1優先と第6条。既存の通常修正・検査後公開の委任を適用。

## Global Constraints
- src/core.mjs、登録広告ID、SEOメタ、robots/sitemap、保存・送信の仕様を変更しない。
- Webの借入入力値を外部へ送信・保存しない。
- Android SDK・購入処理と同梱リリースを変更しない。
- 表示条件・表示例と利用者の実績を混同しない。

## Review Focus
- 条件変更時に古い結果を表示せず、再計算待ちを明示。
- 元利均等・元金均等と0%・600回・最大金額の長い表示。
- 狭幅375/390pxと文字拡大で、入力と表以外に横はみ出しがない。
- PCで再計算しても条件から離れず、狭幅では結果へ移動できる。
- 未配信Web広告の余白を除去し、ネイティブ広告の余白制御は維持。
